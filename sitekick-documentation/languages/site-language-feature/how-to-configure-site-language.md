# How to configure site language?

Configuring the language for your live website involves two steps:

**Step 1: Set the Default Language for Your Site**

1. Go to the **Site Editor.**
2. Click **Settings > General**.
3. Set the **Site Language** to your desired default (e.g., English, Spanish).
4. Save changes.

> This sets the primary language metadata for your site.

**Step 2: Enable Multilingual Options with GTranslate**

1. Navigate to **Settings > GTranslate**.
2. Choose which additional languages you want to offer.
3. Customize the display style and location of the language switcher.
4. Save changes.

> Visitors will now see a language selector on your site and can view translated versions instantly.
