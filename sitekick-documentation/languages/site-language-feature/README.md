# Site Language feature

Once you select your target language, the built-in text on several widgets will be translated into your target language automatically. However, please note that widget text has been pre-translated and cannot be customized.

**What languages are offered?**

**The languages offered include** Dutch, Italian, English, Turkish, English (UK), Portuguese, French, Spanish (LATAM), German, Spanish (Spain), Polish, Finnish, Latvian, Lithuanian, Arabic, Swedish, Icelandic, Norwegian, Danish, Hebrew, Russian, Catalan, Romanian, Chinese (Traditional), Chinese (Simplified), Greek, Korean, Vietnamese, Indonesian.

_NOTE: Some widgets allow you to select a widget language in the Content Editor (for example, Business Hours, Cookie Notifications). If you selected a language for the widgets, they would remain in the selected language until you change the Site Language._
