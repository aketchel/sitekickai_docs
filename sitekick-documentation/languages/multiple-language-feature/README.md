# Multiple-Language feature

This feature allows you to select a default language, add your preferred languages, or use the free Google Translate feature built-in to the editor.

**What languages are offered?**

**The languages offered include** Dutch, Italian, English, Turkish, English (UK), Portuguese, French, Spanish (LATAM), German, Spanish (Spain), Polish, Finnish, Latvian, Lithuanian, Arabic, Swedish, Icelandic, Norwegian, Danish, Hebrew, Russian, Catalan, Romanian, Chinese (Traditional), Chinese (Simplified), Greek, Korean, Vietnamese, Indonesian.
