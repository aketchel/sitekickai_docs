# How to select the default language?

This guide is for the **Multiple-Language Feature**.

To manually set the default language of your site:

1. Go to the **Site Editor**.
2. In the left panel, click **Pages**, then select **Add site languages** or **Manage site languages**.
3. Next to the current default language, click **Change**, and select a new default language.

> ⚠️ **Important:**\
> The default language must be selected _before_ adding additional languages. Once you've added other languages, you cannot change the default language.\
> All new content must be created in the default language and then translated into others using the **Multiple-Language Feature**.
