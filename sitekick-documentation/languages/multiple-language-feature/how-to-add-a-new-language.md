# How to add a new language?

To add additional languages to your site using the **Multiple-Language Feature**:

1. In the **Site Editor**, go to **Settings** > **GTranslate**.
2. Under the **Languages** section, click **Add Language**.
3. Select the desired language from the list.
4. Click **Save**.

Once a new language is added, a duplicate version of each page will be created, which you can translate either manually or automatically using the built-in **GTranslate** feature.

> 💡 **Tip:**\
> You can switch between languages at any time using the language switcher embedded in your site’s header or footer. You can also edit each language version individually in the **Design Editor**.
