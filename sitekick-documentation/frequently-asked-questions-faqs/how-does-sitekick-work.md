# How does Sitekick work?

Sign in at [Sitekick CMS](https://cms.sitekick.ai/), select your website and choose the workflow for your task:

- **Your Sitekick:** open **Ask Sitekick** from the workspace or use **Plan a project** for the full saved conversation. Review proposed tasks before starting them.
- **Pages:** open an existing page, preview and select content, prepare an alternative and review the change. New pages start as drafts.
- **Whole-site projects:** select the website, review a blueprint and credit estimate, generate a private candidate and explicitly approve its exact release for publication.
- **Advanced editor / Advanced WordPress tools:** use the installed native tools for detailed layout, page management and other authorized settings.

See [Work with Your Sitekick](../working-with-our-ai-site-editor/your-sitekick-conversations.md), [review and publication](../working-with-our-ai-site-editor/review-publish-and-recover.md), and [Whole-site projects](../working-with-our-ai-site-editor/whole-site-projects.md). These guides describe the current CMS workspace; older Design Editor articles may show a different interface.
