# How to Add Google Analytics & Google Tag?

1. In the **Site Editor**, go to **Analytics > Google Analytics**.
2. Enter your **Google Analytics Measurement ID** (e.g., `G-XXXXXXX`).
3. Enable **Stealth Mode** or optimized loading if desired.
4. Save changes.

_For advanced tracking:_

* You can manually insert your **Google Tag Manager** script into the header using the **Insert Headers and Footers** plugin (pre-installed).
