# How to Customize Your 404 Page?

Below are the steps to customize the 404 page on your website.

1. Login to your **Site Editor**.
2. Navigate to **Appearance > Theme File Editor**.
3. Look for a file or template labeled `404.php`.
4. If you’re using the **Design Editor**, go to **Templates > Theme Builder**, choose the **404 Template**, and click **Edit**.
5. Customize the content, layout, or design using the drag-and-drop tools.
6. Click **Update** to save your changes.
