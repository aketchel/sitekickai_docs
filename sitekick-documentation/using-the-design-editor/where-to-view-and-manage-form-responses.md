# Where to View and Manage "Form" Responses?

To view and manage form responses, you need to do the following:

1. Go to the **Site Editor**.
2. Navigate to **Contact Forms** in the sidebar.
3. Click on **Entries** to see submissions for each form.

You can also export responses to CSV or set up email notifications and webhooks.
