# How to Add Pop-ups?

Follow the steps below to add pop-ups for your website.

1. Open your site in the **Design Editor**.
2. Create or edit the section you want to turn into a popup trigger.
3. Use the **popup trigger element** inside the Design Editor (e.g. a button or section with a popup action).
4. Configure the popup settings:
   * Trigger: on scroll, exit intent, or time delay.
   * Conditions: which pages the popup shows on.
5. Save and publish.

You must use Elementor for full popup trigger configuration. The native popup setup in the Sitekick Design Editor does not include advanced triggers.
