# How to Add an Advanced Grid?

Advanced grids allow you to place elements in a freestyle composition without an automatic layout. Below are the steps on how to add an Advanced Grid.&#x20;

To create a responsive grid layout:

1. In the **Design Editor**, add a new **Flex Container**.
2. Inside it, insert columns or inner containers.
3. Use the **Advanced tab** to adjust:
   * Margins and padding
   * Responsive behavior
   * Backgrounds or borders

Pro Tip: Use **nested containers** for more complex grid layouts.
