# How to Edit the Elements in the Advanced Grid?

* Click on the specific element (text, image, button).
* Use the left panel to edit:
  * **Content** (text, links, media)
  * **Style** (font, colors, spacing)
  * **Advanced** (margin, padding, motion effects)
* Use a responsive preview to adjust for tablet or mobile.

Note: As there are several different elements, the popups and toolbars will most likely be different as well. This guide was made to just show you, in general, how editing is done.
