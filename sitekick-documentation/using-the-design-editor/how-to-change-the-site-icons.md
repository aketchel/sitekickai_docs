# How to Change the Site Icons?

To change the site icon, follow the steps provided.

To change the site favicon (browser icon):

1. Go to the **Site Editor**.
2. Navigate to **Appearance** > **Customize**.
3. Click **Site Identity** and upload your desired icon under **Site Icon**.
4. Save changes.
