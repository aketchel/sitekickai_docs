# How to See a Preview of the Site Layout in Different Devices?

To see a preview of your site layout on different devices, please complete the following steps.

1. Open your page in the **Design Editor**.
2. In the bottom left, click the **Responsive Mode** icon (desktop/tablet/mobile).
3. Adjust layouts per device type and preview instantly.
4. Changes made in each mode apply only to that device unless overridden.
