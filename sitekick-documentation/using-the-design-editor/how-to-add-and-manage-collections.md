# How to Add and Manage Collections?

#### 📌 How to Add and Manage Collections

Collections allow you to display a group of similar items—like services, team members, products, or testimonials—in a dynamic layout. Here’s how to create and manage them:

***

**✅ What Is a Collection?**

A **Collection** is a set of reusable content entries that can be added to a section of your site. Each entry includes text, images, and links that you can customize. Common examples include:

* Project galleries
* Testimonials
* Services
* Team profiles
* FAQs

***

**🛠️ How to Add a Collection to Your Page**

1. **Log into the Site Editor** from your dashboard.
2. Go to the page where you want to insert the Collection.
3. Click **“Edit with Design Editor”**.
4. Search for the **“Collection” widget** in the sidebar (sometimes called “Loop,” “Grid,” or “Repeater”).
5. Drag it into the page.
6. Choose an existing Collection or create a new one.
7. Style it as needed.

***

**➕ How to Add Items to a Collection**

1. In the **Site Editor**, click **Collections** in the sidebar.
2. Choose the Collection type (e.g., Testimonials, Projects, Services).
3. Click **“Add New”** to create a new entry.
4. Fill in:
   * **Title**
   * **Image or Icon**
   * **Description**
   * **Optional Link/Button**
5. Click **Publish** to save it.

Once saved, it will automatically appear on all pages where that Collection is displayed.

***

**✏️ How to Edit or Remove a Collection Item**

1. Go to the **Collections** tab in the Site Editor.
2. Click the item you want to edit.
3. Make your changes and click **Update**.
4. To delete, click **Move to Trash** on the right sidebar.

***

**🔁 Collection Items Not Updating?**

If you’ve added or edited a Collection item and don’t see changes:

* Make sure the page has been saved and refreshed.
* Check if your **Design Editor's cache** needs to be cleared (Tools > Regenerate CSS).
* Ensure the **Collection widget** is properly linked to the correct Collection type.
