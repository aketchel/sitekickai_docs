# How to Add Flex Element Widgets?

1. Add a **Flex Container**.
2. Drag widgets (e.g., text, icons, buttons) into it.
3. Use the container settings to define:
   * **Direction** (row or column)
   * **Gap/spacing**
   * **Justify/align**

Use this for responsive designs and faster loading layouts.
