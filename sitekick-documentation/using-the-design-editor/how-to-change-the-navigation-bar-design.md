# How to Change the Navigation Bar Design?

To change the navigation design, the following steps are needed to be done.

1. In the **Design Editor**, click on the **Header** section.
2. Select the navigation menu element.
3. In the **Style** tab, adjust font, background, padding, alignment, and color.
4. Use **Responsive Mode** to optimize design for mobile/tablet.
