# How to Add a Section on a Page Using Flex Mode?

* In the **Design Editor**, click the **“+” icon** to add a new section.
* Choose a **“Flexbox Container”** layout.
* Use our Design Editor's **Flex Mode** tools to:
  * Align items horizontally/vertically
  * Adjust spacing and sizing
* Drag elements (text, images, buttons) into the section.
