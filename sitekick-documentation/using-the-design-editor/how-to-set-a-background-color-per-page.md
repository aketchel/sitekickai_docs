# How to Set a Background/Color per Page?

To set a background/color per page, do the following steps provided.

1. Go to the page using the **Design Editor**.
2. Click the **Section** or **Page Settings** gear icon.
3. Under **Style**, choose a background color, gradient, or image/video for that page.
4. Save and publish.
