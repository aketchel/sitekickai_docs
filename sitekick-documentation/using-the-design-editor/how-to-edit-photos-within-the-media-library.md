# How to Edit Photos within the Media Library?

To edit photos within the Media Library, please follow the steps below.

1. In the **Design Editor**, click on any image widget.
2. Select **Choose Image > Media Library**.
3. Hover over the image and click **Edit**.
4. You can crop, rotate, or resize the image directly in the browser.
5. Click **Save**, then **Insert**.
