# How to Change a Logo/Image Using Image Picker?

The **Image Picker** allows you to swap out any logo or image element:

1. In the **Design Editor**, click on any image or logo block.
2. The **Image Picker** will appear in the left sidebar.
3. Click **“Choose Image”**, upload or select an image.
4. Click **“Insert Media”** and then **“Update”**.
