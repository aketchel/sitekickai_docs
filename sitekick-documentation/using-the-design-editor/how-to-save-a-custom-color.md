# How to Save a Custom Color?

If you want to save a custom color so you can reuse it across your site, follow these simple steps.

1. While editing in the **Design Editor**, open any color picker.
2. Choose your desired color.
3. Click the **+** icon under **Global Colors** to save it.
4. You can now reuse that color throughout the website for consistency.
