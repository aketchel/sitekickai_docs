# How to Edit Forms on the Site?

1. In your **Site Editor**, go to **Contact Forms** in the sidebar.
2. Click the form you want to edit (e.g., “Default Contact Form”).
3. Drag and drop new fields, edit existing ones, or change settings.
4. Save changes.

To reflect them on the site:

* Use the **Design Editor**, and ensure the form shortcode is embedded correctly in a widget.
