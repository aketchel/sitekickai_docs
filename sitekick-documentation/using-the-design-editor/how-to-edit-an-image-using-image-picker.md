# How to Edit an Image Using Image Picker?

You can edit any image as follows:

1. Click on the image block in the **Design Editor**.
2. In the Image Picker panel, change:
   * **Alt text** for SEO
   * **Size** or **alignment**
   * Add a **link** or **caption**
3. To crop or resize, edit it before uploading, or use the Media Editor.
4. Click **“Update”** to save.
