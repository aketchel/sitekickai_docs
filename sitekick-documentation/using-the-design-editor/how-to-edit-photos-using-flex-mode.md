# How to Edit Photos Using Flex Mode?

1. Select the **Section** or **Container** holding your image.
2. In **Layout > Display**, choose **Flex**.
3. Adjust alignment, justification, and direction to control the photo's positioning.
4. You can also use **Advanced > Custom CSS** for further tweaks.
