# How to Create and Manage your Blog?

To create and manage your blog:

1. Go to the **Site Editor**.
2. In the left sidebar, navigate to **Posts** > **Add New** to create a new blog post.
3. Use the editor to add your content, images, SEO metadata (via the SEO tab), and publish the post.
4. To manage existing posts, go to **Posts** > **All Posts**.

Your blog layout and styling can be customized via the **Design Editor** (see: "How to Change the Site Layout").
