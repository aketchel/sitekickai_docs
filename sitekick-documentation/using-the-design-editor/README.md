# Using the Design Editor

For the current CMS, open a page and choose **Advanced editor** for Elementor, or **Advanced WordPress tools** below **Ask Sitekick** for WordPress page management. See [Review, publish and recover changes](../working-with-our-ai-site-editor/review-publish-and-recover.md) for the current preview and approval flow.

The articles below include legacy Design Editor screenshots and controls. Use them when they match your editor; they do not describe the Your Sitekick conversation panel. Advanced tools depend on your permissions and installed features.
