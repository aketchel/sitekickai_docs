# How to embed a Meta (Facebook) Pixel to your Landing Page or Site

You can add Facebook Tracking Pixels to your responsive site to track events. Create your Facebook Tracking Pixel code in the [Facebook Pixel tab](https://www.facebook.com/business/url/?href=https%3A%2F%2Fwww.facebook.com%2Fads%2Fmanager%2Fpixel%2Ffacebook_pixel\&cmsid=952192354843755\&creative=link\&creative_detail=advertiser-help-center\&create_type\&destination_cms_id\&orig_http_referrer=https%3A%2F%2Fhelp.dudamobile.com%2Fhc%2Fen-us%2Farticles%2F221092607-How-to-track-Contact-Form-conversions).

#### Add Facebook Tracking Pixel

To embed a Facebook Pixel:

1. **Generate your Facebook Pixel** from your Meta Ads Manager.
2. **Copy the full script** provided by Facebook.
3. In the **Site Editor**, go to the **Insert HTML Snippet** menu.
4. Paste your Facebook Pixel code in the appropriate section (usually the `<head>` or `<body>` area).
5. Save and publish the site.

This allows you to track visitor behavior, conversions, and ad performance across your site.
