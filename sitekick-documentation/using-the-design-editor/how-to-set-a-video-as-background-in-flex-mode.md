# How to Set a Video as Background in Flex Mode?

If you want to give your website more character, you can set a video as background. Follow the steps below.

1. In the **Design Editor**, select the section you want to apply the background video to.
2. In the **Layout** or **Style** tab, choose **Background > Video**.
3. Paste a YouTube, Vimeo, or self-hosted video link.
4. Set playback options (loop, mute, autoplay).
