# Advanced Analytics - Detailed Breakdown

You can access the advanced Analytics by following the Steps below&#x20;

If you’re ready for more powerful tracking:

* Enable **Advanced Mode** in the Analytics tab.
* Add your **Google Tag Manager (GTM)** ID.
* This allows you to track:
  * Click events
  * Scroll depth
  * Form submissions
  * Custom conversions

Our system automatically injects these through **CAOS** so you don’t have to edit code.
