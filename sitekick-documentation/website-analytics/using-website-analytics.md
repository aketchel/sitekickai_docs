# Using Website Analytics

**Using Website Analytics**

Sitekick integrates Google Analytics through the **Analytics Setup tab** in your **Site Editor**. Here's how to get started:

1. Install your Google Analytics Measurement ID (G4 ID) via:
   * **Settings → Analytics → Google Analytics**
2. We use **CAOS (Complete Analytics Optimization Suite)** behind the scenes to:
   * Improve loading speed
   * Ensure GDPR compliance
   * Allow local hosting of analytics scripts

Once set up, you'll be able to view basic page views and traffic sources
