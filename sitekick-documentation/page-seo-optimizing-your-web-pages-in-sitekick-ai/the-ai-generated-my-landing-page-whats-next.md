# The AI generated my landing page, what's next?

* **Local Business Schema**- is a form of structured data markup code that is used to make it easier for search engines to identify what type of organization you are and what you do.
* **Site Meta Title** - refers to the text that is displayed on search engine result pages.
* **Site Meta Description** - informs and interests users with a short, relevant summary of what your website is about.
* **Alt Texts** - is used to describe images on your page.&#x20;
* **Image resolution** -  the quality of the images being uploaded on your landing page.&#x20;
* **Customized domain** - A website domain that is customized for your business.&#x20;
* **SSL Certificate** - a security protocol that creates an encrypted link between a web server and a web browser.
* **Site Icons** - associated with a website to be displayed with bookmarks, in the URL bar, on tabs, and anywhere else where a website has to be identified visually.
