# Sitekick public documentation

- [Sitekick CMS](sitekick-documentation/README.md)
- [Sitekick Studio](sitekick-studio-documentation/README.md)

Each product has its own `SUMMARY.md` and Markdown content root. Edit customer-facing documentation here; the website's docs sync pipeline publishes both products at [docs.sitekick.ai](https://docs.sitekick.ai), with Studio under `/studio`.

The website generates navigation, search, HTML, Markdown, and read-only MCP resources from this repository. Keep relative article links within their product folder and update the corresponding `SUMMARY.md` when adding or moving a page.
